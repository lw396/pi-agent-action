# 与上游的偏离

本仓库的功能和行为尽量与 [anthropics/claude-code-action](https://github.com/anthropics/claude-code-action)（下称"上游"）保持一致。下表登记每一项偏离，并说明原因。

## 规则

- 只有以下 4 类原因允许偏离：

  | 类别             | 含义                                   |
  | ---------------- | -------------------------------------- |
  | `pi-capability`  | pi 没有某项能力，或者做法不同          |
  | `multi-provider` | 支持多个模型 provider 带来的差异       |
  | `branding`       | 本项目不是官方产品，不使用 Claude 品牌 |
  | `scope`          | 本项目明确不做                         |

- 新增或修改偏离时，同一个 PR 中必须同步更新本表。没有登记的偏离视为缺陷。
- "用户可见"为"是"的行，要出现在 README 的迁移对照表中。
- 难以撤回的偏离另写 ADR，在本表中链接过去。
- 从上游 cherry-pick 之前，先在本表中查一下涉及的区域。
